AI Workflow System

View repository ↗

Problem

AI automation can become difficult to reason about when decisions are hidden inside scattered prompts and one-off scripts. I wanted a visual way to represent each decision step, make branching explicit, and create a foundation for inspectable workflow execution.

What I Did

I set up a Next.js application with React Flow for the visual workflow canvas, Inngest for durable execution, OpenAI for AI decision steps, and shadcn/ui for the interface foundation. Each node is designed around a simple YES/NO outcome so the workflow can be followed like a decision tree instead of a black box.

What Came of It

The project now has a clear base for a visual AI workflow product: the stack is in place, the execution model is explicit, and the next iterations can focus on branching, run history, and clearer execution logs without having to rethink the foundation.
